## repository structure
*`src/Main.java` - Application entry point and menu driver.
*`src/Book.java` - Class defining book attributes & logic.
*`src/LibraryManager.java` - Core operational management methods.
*`src/Members,java` - class defining library user data.
*`Book.txt - System data record for book inventory.
*`Members.txt` - System data record for registered members.

## version control workflow
This project utilizes a feature-branching workflow (`feature/task9-demo`) merged directly into `main` to track feature development refactoring.
